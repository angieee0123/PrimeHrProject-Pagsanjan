🎯 WHAT IS THIS FEATURE?

  The Excel Import Feature allows you to import historical leave records 
  from Excel files (like "ate beng.xlsx") into the HR system database.
  
  When you import:
  ✓ All employee leave credits are recorded
  ✓ All deductions are tracked
  ✓ Complete transaction history is created
  ✓ Final balances are calculated and stored
  ✓ Everything is audited and traceable

================================================================================

📋 WHAT GETS RECORDED?

  In the Database:
  ─────────────────
  
  1. LEAVE BALANCES (Summary per leave type)
     - Total Credits Earned
     - Total Credits Used
     - Final Available Balance
     
  2. LEAVE TRANSACTIONS (Complete History)
     - Every earning record
     - Every deduction record
     - Running balance for each transaction
     - Before→After balance chain

  Example:
  ─────────
  Employee: Ate Beng (ID: 15), Year: 2024
  
  leave_balances:
    VL: Earned=12.5, Used=3.0, Available=9.5
    SL: Earned=10.0, Used=1.5, Available=8.5
  
  leave_transactions:
    1. January: VL +1.0 → balance becomes 1.0
    2. January: SL +0.833 → balance becomes 0.833
    3. February: VL +1.0 → balance becomes 2.0
    4. February: SL +0.833 → balance becomes 1.666
    ... (continues for each month)

🚀 QUICK START (5 MINUTES)

  Step 1: Go to Leave & Benefits Page
  ─────────────────────────────────────
  
  Step 2: Click "Import Records" Tab
  ──────────────────────────────────
  
  Step 3: Click "Import Leave Records" Button
  ───────────────────────────────────────────
  
  Step 4: Select Employee
  ─────────────────────────
  └─ Choose from dropdown (shows ID, Name, Department)
  
  Step 5: Upload Excel File
  ──────────────────────────
  └─ Select .xlsx or .xls file (max 5MB)
  └─ Your file should have data starting from row 6 with:
     * Column A: Month name
     * Column D: VL Earned
     * Column F: VL Used
     * Column H: SL Earned
     * Column J: SL Used
     * Column M: VL Balance
     * Column N: SL Balance
  
  Step 6: Click "Import Records"
  ──────────────────────────────
  └─ System validates and imports data
  └─ Shows success message
  └─ Auto-redirects to Transaction History
  
  Step 7: Verify in Database
  ────────────────────────────
  └─ See all imported transactions
  └─ Check Leave Balances summary
  └─ Confirm everything looks correct

📊 EXCEL FILE FORMAT

  Your Excel file must look like this:

  Rows 1-5:  HEADER (Employee info)
  ─────────────────────────────────
  Row 1: Employee Name: Ate Beng
  Row 2: Position: Administrative Officer
  Row 3: Department: Human Resources
  Row 4: Year: 2024
  Row 5: (blank or notes)

  Row 6+: DATA (Monthly records)
  ───────────────────────────────
  
  Column →  A        B        D            F            H            J            M         N
  Row 6→   Month    Notes   VL Earned   VL Used     SL Earned    SL Used      VL Bal    SL Bal
           ─────────────────────────────────────────────────────────────────────────────────
           January  VL1      1.0         0           0.833        0            1.0       0.833
           February VL1      1.0         0           0.833        0            2.0       1.666
           March    FL1      0           1.0         0.833        0            1.0       2.499
           April    (blank)  1.0         0           0            0.166        2.0       2.333
           ... more months ...

  IMPORTANT:
  ──────────
  ✓ Must have header in rows 1-5
  ✓ Data MUST start from row 6
  ✓ Each row = one month
  ✓ Columns A, B, D, F, H, J, M, N are READ
  ✓ All other columns are IGNORED
  ✓ Column D, F, H, J, M, N must have numbers (not text)

================================================================================

✅ WHAT HAPPENS AFTER IMPORT

  1. System reads Excel file
  2. Parses data from row 6 onwards
  3. For each month creates transactions for:
     - VL (Vacation Leave) earnings and deductions
     - SL (Sick Leave) earnings and deductions
  4. Calculates running balances (before → after)
  5. Updates leave_balances table with totals
  6. Updates leave_transactions table with history
  7. Returns success message
  8. All marked with "leave_import" for audit trail

  Result:
  ───────
  Employee's complete leave history is now in the system!
  Available for leave requests, reports, and payroll.

================================================================================

🔍 WHERE TO VERIFY RESULTS

  Option 1: In Web UI
  ──────────────────
  Leave & Benefits → Transaction History Tab
  └─ See all imported transactions
  └─ Filter by employee, leave type, date
  └─ Verify balances

  Option 2: In Database (SQL)
  ────────────────────────────
  -- See leave balances
  SELECT * FROM leave_balances 
  WHERE employee_id = 15 AND year = 2024;
  
  -- See transactions
  SELECT * FROM leave_transactions 
  WHERE employee_id = 15 
  AND reference_type = 'leave_import'
  ORDER BY transaction_date;

================================================================================

⚠️ IMPORTANT RULES

  1. Excel Format: STRICT
     └─ Must have header rows 1-5
     └─ Data must start at row 6
     └─ Columns must be exact order

  2. File Format: MUST BE
     └─ .xlsx (Excel 2007+)
     └─ OR .xls (Excel 97-2003)
     └─ NOT Google Sheets, CSV, etc.

  3. File Size: MAX 5MB
     └─ Typical files are 50-500KB

  4. Numeric Values: MUST BE NUMBERS
     └─ Columns D, F, H, J, M, N must have numbers
     └─ Not text, not formulas

  5. No Duplicates: ONE IMPORT PER EMPLOYEE PER YEAR
     └─ Can't import same employee twice in same year
     └─ Would overwrite previous data

  6. All or Nothing: NO PARTIAL IMPORTS
     └─ If ANY error occurs, NOTHING is saved
     └─ Database rolls back completely
     └─ You get error message to fix and retry

================================================================================

❌ COMMON ERRORS & FIXES

  Error: "Invalid Excel format"
  └─ FIX: Make sure file is .xlsx or .xls
  
  Error: "File size exceeds 5MB"
  └─ FIX: Use smaller Excel file or split into multiple files
  
  Error: "Employee not found"
  └─ FIX: Double-check employee ID exists in system
  
  Error: "Data starts before row 6"
  └─ FIX: Move data to start at row 6, put header in rows 1-5
  
  Error: "Invalid numeric values"
  └─ FIX: Check columns D, F, H, J, M, N only have numbers
  
  Error: "Duplicate import"
  └─ FIX: This employee/leave type/year already imported
